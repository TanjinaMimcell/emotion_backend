*********Real-Time Facial Emotion Detection***********

Project Overview:
This project detects human emotions in real-time using a webcam. It combines Python, OpenCV, and DeepFace to identify emotions like happy, sad, angry, surprise, fear, neutral, and disgust, and displays a color-coded rectangle around the face with motivational advice for each emotion.

Features:

Real-time face detection with OpenCV

Emotion recognition using DeepFace

Dynamic advice display based on detected emotion

Works with multiple faces in the frame


Installation:

1. Clone the repository:
git clone https://github.com/TanjinaMimcell/emotion_backend.git

2. Install dependencies:
pip install -r requirements.txt

3. Run the project:
python main.py


***Note: Make sure your webcam is connected.
